Deep Learning Project 1 — Assignment Specification

1) Overview

You are provided with a custom dataset containing 30,000 labelled images across nine pattern classes. Your task is to design, train, evaluate, and justify a deep learning classifier using Keras with the TensorFlow backend.

The dataset may contain irrelevant or incorrectly labelled images, reflecting imperfections in data collection. You should investigate the data and use systematic experimentation to support your modelling decisions.

This is an individual assessment. You must submit a trained model, a reduced notebook, and a report. Your work will be assessed according to the rubric provided on Canvas.

Due date: 11:59 PM, Wednesday, December 9, 2026 (Vietnam time).

2) Files You Will Receive

- project1_instructions.md and project1_instructions.txt: these assignment instructions in Markdown and plain-text formats. Both contain the same content.
- student_dataset.npz: the labelled dataset, containing:
  - images: shape (30000, 32, 32), dtype float32. Each sample is a single-channel image with values in [0, 1].
  - labels: shape (30000,), containing string labels from {a, b, c, d, e, f, g, h, k}.

There is no predefined training/validation split. You must create and document your own split(s), using validation data to guide model selection.

Your submitted model will be evaluated on a separate, private instructor_dataset.npz file with the same fields, image dimensions, data types, and label set. The number of samples may differ.

4) Report Requirements

Your report must clearly present the following:

- Objective and Approach: Introduce the classification task and summarise your proposed solution.
- Dataset Inspection: Examine image examples, value ranges, class distribution, and potential data-quality issues.
- Validation and Preprocessing: Describe and justify your training/validation split(s), random seeds, and preprocessing choices. Explain how you prevent data leakage.
- Model Architecture: Describe and justify your model type, layers, and sizes. Report the number of parameters.
- Training Methodology: Explain your choices of activation functions, loss function, optimiser, and regularisation, connecting them to relevant theory.
- Experiments and Results: Compare the approaches you tried, including a baseline. Present relevant learning curves and explain how the evidence informed your final model selection.
- Evaluation and Error Analysis: Report validation performance, examine misclassifications, and discuss computational efficiency. State the hardware and measurement procedure for any reported execution times.
- Reflection and Reproducibility: Discuss limitations, possible improvements, and key insights. Record random seeds, Python and package versions, and execution details needed to reproduce your results.
- Sources and Acknowledgements: Cite external code, pretrained models, and other materials, and disclose AI use as required by the course.

Write explanations in Markdown cells and support them with relevant code, figures, tables, and outputs. Remove unnecessary logs and repetitive content. Ensure that code and figures remain legible in the exported PDF.

- Supporting Libraries: NumPy, Matplotlib, pandas, scikit-learn, seaborn, and similar standard scientific Python packages are permitted.
